# NEXUS College Management System
A BCA-friendly high-tech prototype for a Modern Database System project.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge/Firefox.
3. Faculty demo password: `admin123`.
4. Student portal: enter any registration number to create a profile, then fill mandatory fields.

## Features
- Separate Faculty and Student portals
- Faculty authentication
- Course and semester selection
- Add/edit/rename/delete/block/unblock student records
- Course add/rename/delete
- Student registration-number login
- Mandatory profile fields
- Search and CSV export
- Responsive futuristic UI
- localStorage persistence

## Important
This is a frontend prototype. For a real college deployment, replace localStorage authentication with a backend and database such as MySQL/PostgreSQL, hash passwords, validate all server-side inputs, use sessions/JWT securely, and implement role-based access control.
